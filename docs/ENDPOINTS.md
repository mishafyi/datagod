# DataGod — API Endpoints

> Generated by `scripts/gen_endpoints_doc.py` from the OpenAPI schema.
> The interactive, always-current version is the **Swagger UI at `/docs`** (HTTP Basic auth).
> Every endpoint requires the `X-API-Key` header except `GET /health`.

**72 endpoints across 24 groups.** Base URL: `https://datagod.example.com`

## Health

Liveness probe. `GET /health` is public (no key required).

| Method | Path | Summary |
|--------|------|---------|
| GET | `/` | API index: sources and endpoint map |
| GET | `/health` | Liveness probe (public, no API key) |

| Method | Path | Summary |
|--------|------|---------|

## EDGAR

SEC EDGAR — corporate filings, XBRL financials, full-text search. The Frames endpoint compares one concept across all filers in a single call.

| Method | Path | Summary |
|--------|------|---------|
| GET | `/edgar/company/{cik}` | Company profile and filing history (CIK or ticker) |
| GET | `/edgar/concept/{cik}/{concept}` | One XBRL concept's history for a company |
| GET | `/edgar/financials/{cik}` | All XBRL financial facts for a company |
| GET | `/edgar/frames/{concept}` | One concept across all filers (cross-company) |
| GET | `/edgar/search` | Full-text search inside filing documents |
